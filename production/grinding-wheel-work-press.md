# 压块

区别于[旧压块](/production/press.md)

结构
--------------------------------------------------------------------------
### 

Column                              | Type      | Null | Note
------------------------------------|-----------|------|-------
`id`                                | int       | No   | 与`grinding_wheel_work` 共用主键
`status`                            | int       | No   | Lookup `grinding-wheel-work-press-status` 已创建(1)、已交付(5)、已接收(9)
`quantity`                          | int       | Yes  | 
`note`                              | string    | Yes  | 
`received_at`                       | int       | Yes  | 

操作
--------------------------------------------------------------------------
### 录入数量
`fill`. 填写压块实际数量。此时状态为”已创建“。

### 交付
`deliver`:

- 更新状态为”已交付“。

### 拒绝
`deny` 烧结员发现收到的数量有出入时可以拒绝，让压块员重新填写数量:

- 回滚状态为”已创建“。

### 接收
`receive` 烧结员接收：

- 更新状态为”已接收“。
- 填充 `received_at` 为当前时间；
- 新增 `grinding_wheel_work_burn` 记录，承载”烧结“工序；
- 更新砂轮工单工序为”烧结“；
